# Векторный вход и бинарная классификация на скалярном autograd

Учебная реализация бинарных классификаторов OR, AND и XOR на базе
скалярного `Value` из предыдущей лабораторной. Векторный вход
разворачивается циклом скалярных умножений и сложений — новый
autograd-движок не требуется. Только стандартная библиотека Python.

## Запуск

```bash
python vector_binary_classification.py
```

Скрипт выполняет три этапа, проверяет градиенты центральной разностью
и печатает результаты. При успехе в конце выводится строка
`Все проверки пройдены успешно.`

Требуется Python 3.10+.

## Структура

```
assert_close                       — сравнение вещественных чисел с допуском
Value                              — скалярная вершина DAG (из прошлой лабы)
affine                             — w0*1 + Σ w_j*x_j через цикл Value
sigmoid                            — 1 / (1 + exp(-z)) через операции Value
binary_cross_entropy               — BCE одного объекта
mean_binary_cross_entropy          — средняя BCE по датасету
predict_label, classification_accuracy — порог 0.5 и точность
numerical_gradient                 — центральная разность по параметру
VectorBinaryNeuron                 — один sigmoid-нейрон с векторным входом
OneHiddenBinaryClassifier          — скрытый tanh-нейрон + sigmoid-выход
HiddenLayerBinaryClassifier        — произвольное число скрытых tanh-нейронов
```

## Три этапа

### Этап 1. Один sigmoid-нейрон на OR

Модель: `p = σ(w0·1 + w1·x1 + w2·x2)`.
Один нейрон проводит одну аффинную границу; OR линейно разделим.

- Прямой проход проверяется на конкретных числах.
- Градиенты всех трёх весов проверяются центральной разностью.
- Обучение: `learning_rate = 0.5`, `epochs = 300`.
- Требование: BCE < 0.1, accuracy = 1.0.

### Этап 2. Один скрытый tanh-нейрон на AND

Модель: `h = tanh(u0·1 + u1·x1 + u2·x2)`,
`p = σ(v0·1 + v1·h)`.

AND линейно разделим, но здесь скрытый нейрон нужен, чтобы сделать
наблюдаемым прохождение градиента через композицию двух аффинных
операций и нелинейность.

- Градиенты пяти параметров проверяются центральной разностью.
- При заданной инициализации `hidden_weights[1].grad == 0` — это
  корректный результат (вклады четырёх объектов компенсируются),
  что подтверждает и численная проверка.
- Обучение: `learning_rate = 0.3`, `epochs = 300`.
- Требование: BCE < 0.05, accuracy = 1.0.

### Этап 3. Два скрытых tanh-нейрона на XOR

Модель: `h_h = tanh(u_{h0}·1 + u_{h1}·x1 + u_{h2}·x2)` для `h ∈ {1,2}`,
`p = σ(v0·1 + v1·h1 + v2·h2)`.

XOR неразделим одной прямой, но два независимых нелинейных признака
позволяют построить нелинейную границу.

- Девять параметров (`2·3 + 3 = 9`) проверяются центральной разностью.
- Обучение: `learning_rate = 0.5`, `epochs = 500`.
- Требование: BCE < 0.03, accuracy = 1.0.
- Начальные веса двух скрытых нейронов **разные** — иначе они получали
  бы одинаковые градиенты и не приобрели бы разные роли.

## Ключевые моменты

- **`affine`** строит расширенный вход `[1.0, *features]`: `w0` — вес
  постоянной координаты, то есть смещение. Для каждого объекта создаётся
  свежий подграф, но `weights` — общие объекты `Value`.
- **Общие параметры** накапливают вклад от каждого объекта через `+=`;
  поле `weights[j].grad` после `backward()` равно полной производной
  средней BCE по этому весу.
- **Порядок** в эпохе: построить `loss`, вызвать `loss.backward()`,
  только потом обновить `parameter.data`. Иначе замыкания прочитают
  новое значение вместо значения того прямого прохода.
- **`backward()`** сам обнуляет `grad` достижимых вершин, поэтому
  повторный вызов не удваивает градиенты.
- **Признаки и метки** — константные листья; `parameters()` возвращает
  только обучаемые веса, поэтому признаки и метки не обновляются.
- **`mean_binary_cross_entropy`** умножает сумму на `1/n`, а не делит
  на `n`, чтобы использовать только реализованные операции `Value`.

## Ограничения

Реализация не вводит тензоры, матрицы, broadcasting, minibatch,
softmax, регуляризацию и готовые классы PyTorch. Вектор признаков
разворачивается обычным циклом, чтобы связь между формулой, скалярным
DAG и накоплением градиентов оставалась наблюдаемой.
