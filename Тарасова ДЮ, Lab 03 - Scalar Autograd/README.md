# Скалярное автоматическое дифференцирование и обучение одного нейрона

Учебная реализация reverse-mode автоматического дифференцирования
для скалярных величин и обучение одного нейрона с активацией `tanh`
на функции потерь MSE. Без внешних зависимостей — только стандартная
библиотека Python.

## Запуск

```bash
python autograd_lab.py
```

Скрипт последовательно выполняет все эксперименты лабораторной работы,
проверяет результаты через `assert` и печатает сообщения `OK`.
При успехе в конце выводится строка `Все проверки пройдены успешно.`

Требуется Python 3.10+ (используется `math`, f-строки, `zip`).

## Что реализовано

### Класс `Value`

Вершина вычислительного графа. Хранит:

| Поле        | Назначение                                              |
|-------------|---------------------------------------------------------|
| `data`      | значение, полученное в прямом проходе (`float`)         |
| `grad`      | накопленный градиент итоговой функции по этой вершине   |
| `parents`   | кортеж непосредственных родителей (ссылки на `Value`)   |
| `op`        | метка операции (только для чтения и диагностики)        |
| `_backward` | замыкание с локальным правилом обратного прохода        |

Поддерживаемые операции:

- `+`, `-`, унарный `-`
- `*`
- `**` (степень с постоянным показателем)
- `sin`, `exp`, `log`, `tanh`
- отражённые `__radd__`, `__rmul__`, `__rsub__`

Метод `backward()`:

1. Строит топологический порядок обходом `build` (родители раньше потомков).
2. Обнуляет `grad` у всех достижимых вершин.
3. Ставит `self.grad = 1.0` (это ∂J/∂J).
4. Идёт по `reversed(topo)` и вызывает `_backward()` каждой вершины.

### Нейрон `TanhNeuron`

```python
z = w * x + b
y = tanh(z)
```

`weight` и `bias` — долгоживущие объекты `Value`. В каждом вызове
`neuron(x)` создаются новые промежуточные вершины, но параметры
переиспользуются, поэтому их `grad` накапливает вклады всех объектов
датасета.

### Функция потерь

Среднеквадратичная ошибка:

```
L = (1/n) * Σ (ŷ_i - y_i)^2
```

В коде сумма строится циклом по `zip(inputs, targets)`, а деление на `n`
заменено умножением на `1/n` — чтобы использовать только реализованные
операции над `Value`.

## Проверяемые утверждения

Скрипт проверяет:

1. Прямой проход всех поддерживаемых операций.
2. Накопление двух вкладов в общей вершине: для `a*a + a` при `a = 2`
   градиент равен `5`.
3. Ручную трассировку графа `J = tanh(a*b + a)` при `a = 0.5`, `b = 1`:
   - `g_s ≈ 0.419974`
   - после сложения: `g_m ≈ 0.419974`, первый вклад в `g_a`
   - после умножения: `g_a ≈ 0.839949`, `g_b ≈ 0.209987`
4. Совпадение аналитического градиента с центральной разностью
   для `f(x) = sin(x)·exp(x) + x³` в точке `x = 0.37`
   (абсолютная ошибка `< 1e-5`).
5. Совпадение градиентов `weight.grad` и `bias.grad` с численными
   градиентами MSE при нулевых начальных параметрах.
6. Обучение: после 80 эпох с `learning_rate = 0.2`:
   - последняя ошибка `< 0.03`
   - точность классификации `= 1.0`
   - `|weight| > 0.1` и `|bias| > 0.1`

## Ключевые моменты реализации

- В локальных правилах используется `+=`, а не `=`: одна вершина может
  получать вклады от нескольких потомков.
- `visited` в `build` не даёт добавить вершину в `topo` дважды, но не
  отменяет два вклада в `grad` при повторном использовании, например в
  `a * a`.
- Замыкание `_backward` читает `result.grad` в момент вызова, а не при
  создании, поэтому порядок `reversed(topo)` критичен.
- Обновление `parameter.data` выполняется только после `loss.backward()`,
  иначе замыкания прочитают новое значение вместо значения того прямого
  прохода, для которого строился граф.
- `backward()` сам обнуляет `grad` достижимых вершин, поэтому повторный
  вызов не удваивает градиенты.

## Ограничения учебной реализации

- Только скаляры: нет векторов, матриц, батчей, broadcasting.
- Нет вторых производных.
- Показатель степени — обычное число, градиент по нему не строится.
- `log` определён только при `x > 0`.
- Нет оптимизаторов, кроме ручного SGD-шага.
